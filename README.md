# RE_VAULT

RE_VAULT is a personal reverse engineering and malware analysis lab focused on binary analysis, Linux internals, and understanding real-world techniques from a defensive and research perspective.

## Contents

### Phantom-Persistence/
Linux malware research project studying persistence concepts and detection, structured for analysis and defensive understanding.

## Focus Areas
- Reverse engineering C binaries
- Static and dynamic analysis
- Malware behavior research
- Persistence mechanisms and how to detect them
- Obfuscation and anti-analysis concepts

## Planned Additions
- Linux malware samples for analysis
- Packing and unpacking exercises
- Obfuscated binaries
- Reverse engineering notes and tooling experiments

This repository is a learning vault, not a toolkit.

**Disclaimer:** This repository is for educational and research purposes only. All content is designed to improve defensive security capabilities through understanding of how these techniques work.
